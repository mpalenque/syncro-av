Syncro A/V

A 90-minute talk on audiovisual synchrony for live performance.

Book the talk

Colapso — live A/V, real-time visuals

The talk

When a sound and an image happen at the same moment, the brain reads them as one event. This talk explains how that works, and how to use it when you build a live audiovisual show.

Format
Talk with video examples
Duration
90 minutes
For
VJs, musicians, visual artists and designers
Level
Open to all. No code on screen

Program

01

Perception

Seven mechanisms of multisensory integration. They work automatically in any audience, so they are the conditions of the work, before any parameter is touched.

  1. Synchresis
  2. The ventriloquism effect
  3. The McGurk effect
  4. The temporal binding window
  5. Common fate
  6. Rhythmic entrainment
  7. Prediction and reward

02

Precedents

Animation solved synchrony long before computers. Three cases and what live work can take from each.

  1. Bar sheets and click tracks — Chuck Jones and Carl Stalling at Warner Bros.
  2. Prescoring in Akira (1988)
  3. David O’Reilly, Basic Animation Aesthetics (2009)

03

Technique

How to turn a sound into a visual event that the audience reads as one.

  1. Why the volume meter falls short
  2. Envelopes and easing: attack, release, curve
  3. The four phases of a visual event: anticipation, impact, settle, residue
  4. Signals: MIDI, OSC and stems

The argument

Connecting audio to visuals takes minutes. Composing the relationship between them is the actual work.
